# Car picture

By default the dashboard shows Toyota's own render of your car (the same one
the MyToyota app uses). It's downloaded once and kept in the data volume.

To use your own photo instead, put one file here named:

- `car.jpg`, `car.jpeg`, `car.png` or `car.webp`

It's picked up on the next page load, no rebuild or restart needed. A
landscape shot (roughly 16:9) fits best. Delete it to go back to Toyota's
render.

Photos in this folder are git-ignored, so they won't end up in your repo.
